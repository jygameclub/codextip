# 图标来源 / Icon provenance

`Sources/CodexTip/Assets/codex-logo.png` 是本机官方 OpenAI 桌面客户端中用于 Codex 的原始图标资源：

- 来源：`ChatGPT.app/Contents/Resources/app.asar`
- 资源名称：`webview/assets/codex-app-ga-logo-3e5209898ca3.png`
- 原始尺寸：104 × 104 像素
- 使用方式：保持原始图标，在菜单栏按 18 × 18 点显示；可设置大小及颜色的状态圆点由 CodexTip 单独绘制，不对原始 Logo 改色。

The PNG is the original Codex icon resource from the official OpenAI desktop client listed above. CodexTip displays it at 18 × 18 points and draws its own configurable status dot (green / blue by default) alongside it. The original logo is not recolored.

Codex / OpenAI 名称和图标属于各自权利人，用于识别本工具监测的产品。CodexTip 是独立项目，并非 OpenAI 官方产品。

Codex / OpenAI names and logos belong to their respective owners and identify the product being monitored. CodexTip is an independent project, not an official OpenAI product.

表情模式使用 macOS 内置 Apple Color Emoji 字体动态绘制，不随仓库分发表情图片或字体。只替换旁边的状态标识，Codex Logo 不变。

Emoji mode renders with the system Apple Color Emoji font. No emoji images or fonts are bundled; only the adjacent status marker changes, while the Codex logo stays the same.

动画由 CodexTip 的 AppKit 绘图代码生成，仅变换旁边的圆点／系统表情，环绕小点为程序绘制；不分发外部动画素材。文档 GIF 使用演示数据离屏生成。

Animations are generated by CodexTip's AppKit drawing code, transforming only the status dot or system emoji. The orbit bead is drawn procedurally; no external animation assets are bundled. Documentation GIFs are rendered offscreen with demonstration data.
